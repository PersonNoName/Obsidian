# 界面
+ 移动：G 
	+ x/y/z：沿着x/y/z移动（按两下变成局部坐标轴移动）
	+ Alt + G：撤销移动
	+ ctrl：吸附移动
	+ 衰减编辑，可以控制移动所影响的区域![[Pasted image 20260225231847.png]]
+ 缩放：S
	+ x/y/z：沿着x/y/z缩放
	+ Alt + S: 撤销缩放
	+ 使点归于x/y/z轴的0点（可实现拉平的效果）：s + x/y/z + 0
+ 旋转：R
	+ x/y/z：沿着x/y/z旋转
	+ Alt + R: 撤销旋转
+ 隐藏：H
	+ shift + h: 未选中隐藏
	+ alt + h: 撤销xxx
+ 复制：Shift + D
	+ ctrl + z ：只是取消移动
+ 视图：
	+ 1~9
	+ ~ 弹出选中
	+ Alt + 鼠标中键
+ 新建：shift + a
+ 游标：
	+ 移动游标：
		+ shift + 右键（出现在鼠标位置）
		+ shift + c 回到原点
	+ 移动物体：shift + s
+ 摄像头视图：0
+ 渲染：f12
+ 关联材质：ctrl + L
+ 查看变换信息： N

# 点线面选择
+ 选择：
	+ 框选：B
	+ 刷选：C
	+ 取消选择：ctrl + 拖选
	+ 最短路径选择：ctrl + 点选
	+ 选中与该点有联系的所有点： L
	+ 选中一行或一列：alt + 点击
	+ 增加/减小选区：ctrl + +/-
+ 反选：ctrl + i
+ 多个物体同时进入编辑模式：shift选中物体后，tab键、
+ 透视模式：alt + z
# 点线面控制
+ 选择后：G/S/R
